# Hospital Patient Satisfaction Analytics & Prediction

## Project Overview

This project analyzes hospital patient experience data to understand
the factors associated with patient satisfaction and identify
operational areas that may require attention.

## Objectives

- Perform data cleaning and data quality analysis
- Conduct statistical analysis
- Perform exploratory data analysis
- Generate business insights
- Build machine learning models
- Evaluate model performance
- Build a Power BI dashboard

## Project Workflow

Data Understanding
→ Data Cleaning
→ Statistical Analysis
→ Exploratory Data Analysis
→ Business Insights
→ Feature Engineering
→ Machine Learning
→ Model Evaluation
→ Explainability
→ Power BI Dashboard
